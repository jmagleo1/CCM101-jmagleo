# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on investigating the components of cloud infrastructure using a Linux server provided through the KillerCoda Playground. The activity involved examining compute, storage, networking, and operating system resources and documenting the findings as part of a Cloud Infrastructure Assessment Report.

The activity also included researching and comparing the infrastructure services of Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP), as well as designing a simple cloud infrastructure diagram.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate hardware and software resources in a Linux environment.
- Identify compute, storage, networking, and operating system resources.
- Understand how cloud infrastructure components work together.
- Compare equivalent services offered by AWS, Microsoft Azure, and Google Cloud.
- Create professional technical documentation using Markdown.
- Design a simple cloud infrastructure architecture.
- Maintain an organized GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

The major cloud infrastructure components identified during the laboratory were:

- **Compute:** Intel Xeon E312xx CPU with one CPU core.
- **Storage:** 20 GB virtual disk.
- **Networking:** Private IP addresses assigned to the Linux server.
- **Operating System:** Ubuntu 24.04.4 LTS with Linux kernel version 6.8.0-136-generic.

These components work together to provide a functional virtualized cloud server environment.

## Linux Commands Executed

The following Linux commands were used to investigate the cloud server:

- `cat /etc/os-release`
- `uname -r`
- `lscpu`
- `nproc`
- `free -h`
- `lsblk`
- `df -h`
- `findmnt`
- `hostname`
- `hostname -I`

These commands were used to identify the operating system, kernel version, CPU, memory, storage, mounted filesystems, hostname, and IP addresses.
