# Laboratory 05 - Cloud Data Engineer

## Mission Overview
This lab focuses on deploying and managing an S3-compatible object storage server using MinIO, containerized via Docker. The goal is to simulate a real-world cloud storage setup where a storage administrator provisions a server, secures it with credentials, and organizes data using buckets.

## Objectives
- Deploy a MinIO object storage server using Docker
- Access and navigate the MinIO Web Console
- Create and manage a storage bucket
- Upload and verify objects within a bucket
- Document the deployment process and configuration

## Tools Used
- Docker (containerization platform)
- MinIO / pgsty-minio (S3-compatible object storage)
- KillerCoda (cloud playground/sandbox environment)
- Ubuntu 24.04 (base OS for the playground)

## Skills Learned
- Running and configuring containerized services with Docker
- Managing environment variables for container authentication
- Troubleshooting image availability/authorization issues (e.g., deprecated Docker images)
- Navigating cloud sandbox networking tools (Traffic/Ports port forwarding)
- Using an object storage web console to create buckets and upload files
