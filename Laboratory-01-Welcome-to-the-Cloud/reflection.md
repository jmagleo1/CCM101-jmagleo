# Reflection

Completing Mission 1 gave me an introduction to the basic responsibilities of a cloud infrastructure engineer. I learned how to access and work inside a cloud-based Linux environment using KillerCoda.

I learned how to navigate Linux using commands such as pwd, ls, cd, and mkdir. I also learned how to gather system information and manage files and directories.

During the activity, I encountered different errors, especially while working with Git and GitHub. I experienced errors involving file paths, Git configuration, authentication, personal access tokens, repository permissions, and pushing changes to GitHub. These errors helped me understand that troubleshooting is an important skill for a cloud infrastructure engineer.

Creating and organizing my GitHub Cloud Computing Portfolio also helped me understand the importance of documenting technical work properly.

Overall, this activity helped me develop basic Linux, Git, GitHub, documentation, troubleshooting, and cloud computing skills that will be useful in the succeeding laboratory activities.
