# Mission Reflection

After doing the Multi-Cloud Explorer activity #3, I learned more about AWS, Microsoft Azure, and Google Cloud. Before this activity, I only had a basic idea about cloud computing. I thought it was mostly about storing files and using applications online. While doing the activity, I learned that cloud platforms also provide virtual machines, databases, networking, security, AI, and many other services. The cloud platform that impressed me the most was Google Cloud. I found its AI, Machine Learning, data analytics, and Kubernetes services interesting. I think these technologies are important because they are becoming more common in the IT industry. It also made me interested in learning more about how these technologies are used in real projects. AWS, Azure, and Google Cloud have many similarities. All of them provide services for computing, storage, networking, databases, and user access. They also have different locations around the world where companies can deploy their applications. Even though their services have different names, many of them have similar purposes. I also learned that business requirements are important when choosing a cloud provider. For example, Azure would be a good choice for a university that already uses Microsoft products. Google Cloud can be a good option for an AI research company, while AWS can be useful for a startup that needs scalable services. Being a Cloud Solutions Consultant in this activity taught me that we should not just choose a cloud provider because it is popular. We first need to understand what the client needs, including their budget, existing technology, security, and future plans. My GitHub Cloud Computing Portfolio also improved because I added another laboratory and more technical documentation. I also became more familiar with comparing cloud services from different providers. This activity helped me understand cloud computing better. I learned that choosing a cloud provider is not only about knowing its services, but also about knowing which provider is the right fit for a specific situation.
