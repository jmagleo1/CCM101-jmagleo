# Client Recommendations

## Introduction

For this activity, I looked at four different clients with different needs. I realized that the best cloud platform depends on the type of business, existing technology, budget, and technical requirements.

## Client A – Startup Company

### Recommended Platform: AWS

I would recommend AWS for the startup because it has many services that can support a mobile application as it grows. The company can start with the resources it needs and add more as the number of users increases. This is useful for a startup because they may not know exactly how large their application will become in the future.

### Possible Services

- Amazon EC2 – for application computing
- Amazon S3 – for storing files and media
- Amazon RDS – for the application database
- Amazon VPC – for networking
- AWS IAM – for access control

### Recommendation

AWS gives the startup flexibility to start small and scale the infrastructure when the application becomes more popular.

---

## Client B – University

### Recommended Platform: Microsoft Azure

I would recommend Azure for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Moving to Azure would make sense because the university is already using many Microsoft technologies. It can also use Azure to create a hybrid environment instead of moving everything to the cloud immediately.

### Possible Services

- Azure Virtual Machines – for server workloads
- Microsoft Entra ID – for identity management
- Azure Virtual Network – for networking
- Azure Blob Storage – for file storage
- Azure SQL Database – for databases

### Recommendation

Azure would make the transition easier because the university can continue using Microsoft technologies while slowly adding cloud services.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

I would recommend Google Cloud for the AI research company because its requirements are focused on Artificial Intelligence, Machine Learning, and high-performance computing. Google Cloud has services for AI, data processing, virtual machines, and Kubernetes. These can help the company develop and run its research applications.

### Possible Services

- Compute Engine – for computing workloads
- Vertex AI – for AI and Machine Learning
- Google Kubernetes Engine – for containerized workloads
- Cloud Storage – for research datasets
- BigQuery – for data analysis

### Recommendation

Google Cloud is a good match because the company's main work involves AI and large amounts of data.

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

I would recommend AWS for the global e-commerce company because it needs infrastructure that can handle customers from different parts of the world. The company also needs automatic scaling and high availability because online shopping traffic can change quickly. AWS has services that can help distribute traffic, scale resources, store data, and deliver content.

### Possible Services

- Amazon EC2 – for application servers
- Elastic Load Balancing – for distributing traffic
- AWS Auto Scaling – for adjusting resources
- Amazon S3 – for storing files
- Amazon RDS – for database workloads
- Amazon CloudFront – for content delivery

### Recommendation

AWS is a good choice for this scenario because it can support a large and geographically distributed e-commerce application.

---

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Has flexible and scalable services that can support a growing application. |
| Enterprise Organization | AWS | Provides many services that can be used for complex enterprise systems. |
| Microsoft Environment | Azure | Works well with existing Microsoft technologies. |
| AI / Machine Learning | Google Cloud | Has strong AI, ML, and data-related services. |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine provides managed Kubernetes. |
| Global Web Application | AWS | Has global infrastructure and services for scalable applications. |

## Final Recommendation

After comparing the four scenarios, I learned that cloud platform selection should always start with the client's needs.

AWS is a good general-purpose choice, Azure is especially useful for Microsoft environments, and Google Cloud is a strong option for AI, analytics, and Kubernetes.

There is no need to use the same provider for every situation because different projects can have different requirements.
