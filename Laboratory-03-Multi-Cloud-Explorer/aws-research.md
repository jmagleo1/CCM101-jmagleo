# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides on-demand resources for computing, storage, networking, databases, security, analytics, and application development.

One of the main ideas behind AWS is that organizations can obtain computing resources when they need them instead of maintaining all infrastructure physically. This makes AWS useful for both small applications and large enterprise systems that may need to grow over time.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. A Region represents a separate geographic area, while Availability Zones provide isolated infrastructure locations within a Region.

This structure allows organizations to place applications closer to their users and design systems that can continue operating even when an individual infrastructure location experiences a problem. The choice of Region can also depend on performance, compliance, and data-location requirements.

## Cloud Management Console

The AWS Management Console is a browser-based interface for managing AWS services. From the console, users can create and configure resources, monitor services, review account information, and manage security settings.

For example, an administrator can use the console to launch an EC2 instance, create an S3 bucket, configure a VPC, or manage IAM permissions.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can run applications in the AWS environment. Organizations can select instance types based on the amount of processing power, memory, and other resources required by their workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service. It can store files and other types of data such as documents, images, application files, backups, and datasets.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows an organization to create a logically isolated virtual network in AWS. It supports components such as subnets, routing, gateways, and network security configurations.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls authentication and authorization for AWS resources. Administrators can use users, roles, and policies to determine which identities can access particular resources and actions.

## Three Advantages

### 1. Large Service Selection

AWS provides a broad collection of cloud services, allowing organizations to build many parts of an IT environment within one cloud platform.

### 2. Flexible Scalability

AWS resources can be adjusted according to workload requirements. This is useful for applications whose demand changes over time.

### 3. Global Reach

AWS provides infrastructure in multiple geographic locations, allowing organizations to design applications for users in different parts of the world.

## Typical Enterprise Use Cases

AWS can support many enterprise scenarios, including:

- Hosting websites and mobile application backends
- Enterprise application deployment
- Data backup and storage
- Disaster recovery
- E-commerce platforms
- Data analytics
- Artificial Intelligence and Machine Learning workloads
- Globally distributed applications

## Summary

AWS can be a strong choice when an organization needs a broad selection of cloud services, flexible infrastructure, and the ability to scale applications as requirements change. Its combination of computing, storage, networking, and identity services allows companies to construct complete cloud environments.
