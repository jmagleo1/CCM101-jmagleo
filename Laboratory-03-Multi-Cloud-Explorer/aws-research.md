# AWS Research

## Brief Overview

Amazon Web Services or AWS is one of the most widely used cloud platforms today. It provides different services that companies and developers can use without having to build all of their own physical servers.

AWS can be used for websites, mobile applications, databases, file storage, networking, security, and many other IT needs. One thing I noticed about AWS is that it has a very large number of services, so companies have many options depending on what they need.

## Global Infrastructure

AWS has infrastructure located in different parts of the world. It uses Regions and Availability Zones to organize its cloud infrastructure.

A Region refers to a geographic area where AWS has cloud infrastructure. Inside a Region are Availability Zones, which are separate locations designed to help improve the availability of applications.

This is useful for companies with users from different countries because they can choose a Region that is closer to their users. It can also help when a company wants to build a system that is more reliable.

## Cloud Management Console

The AWS Management Console is the website where users can manage their AWS services. Instead of using only commands, users can use the console to create and manage resources through a graphical interface.

For example, I can use the console to create an EC2 instance, configure storage using S3, create a VPC, or manage permissions using IAM.

## Four Core Services

### 1. Amazon EC2

Amazon EC2 provides virtual servers that can be used to run applications. Users can choose different types of instances depending on the computing power and resources needed.

### 2. Amazon S3

Amazon S3 is a storage service used for saving files and other types of data. It can be used for images, documents, backups, videos, and application data.

### 3. Amazon VPC

Amazon VPC is used to create a private network inside AWS. It allows users to configure subnets, routes, and other networking settings for their cloud resources.

### 4. AWS IAM

AWS IAM is used to manage users, roles, and permissions. It helps control who can access AWS resources and what actions they are allowed to perform.

## Three Advantages

### 1. Many Available Services

AWS has a very wide range of services. This gives companies more choices when building their cloud infrastructure.

### 2. Easy to Scale

AWS resources can be increased or decreased depending on the needs of an application. This is useful when the number of users or workload changes.

### 3. Global Infrastructure

AWS has cloud infrastructure in different parts of the world. This can help companies provide better services to users in different locations.

## Typical Enterprise Use Cases

AWS can be used by companies for:

- Website hosting
- Mobile application backends
- Online shopping systems
- Data storage and backup
- Database systems
- Disaster recovery
- Data analytics
- AI and Machine Learning applications

## My Observation

For me, AWS is a good option for organizations that want many choices when building their cloud infrastructure. It can be used for simple projects, but it also has enough services for large and complicated systems.
