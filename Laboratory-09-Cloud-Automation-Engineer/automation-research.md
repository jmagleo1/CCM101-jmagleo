# Automation Research

## Bash Script

A Bash script is a text file that contains a series of Linux commands that can be executed automatically. It helps users perform repetitive tasks faster and with fewer mistakes. The `#!/bin/bash` line, called the shebang, tells the operating system to use the Bash shell to run the script.

## Variables

Variables are used to store values that can be reused throughout a script. Instead of typing the same folder path or filename multiple times, a variable makes the script easier to read, update, and maintain. For example, changing the value of `$BACKUP_DIR` automatically updates every place where it is used.

## Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at a specific date or time. It is important in cloud operations because it allows routine tasks such as backups, updates, and maintenance to run without manual intervention, improving efficiency and reliability.
