
# Mission Reflection: Cloud Automation Engineer

Throughout this semester, I learned that Cloud Computing involves more than just storing files online. Through our laboratory activities, I gained experience with Linux commands, Docker, cloud storage, deployment, monitoring, security, and automation. Each activity helped me understand how cloud systems are created, managed, and maintained.

Automation is important when managing hundreds of cloud servers because it saves time and reduces human error. Instead of performing the same task manually, cloud engineers can use scripts and scheduled jobs to complete repetitive work. However, automation can also be dangerous. A small mistake in a script could affect many servers, delete important data, or interrupt services. This is why testing, reviewing, and monitoring scripts are necessary before using them in a real environment.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. The Bash script executes commands to create folders and compress application data into backup files. Docker Compose, on the other hand, defines application services and their configurations. Both tools help automate tasks, but they are used for different purposes.

Looking back at Laboratory 1 to Laboratory 9, I can see how my understanding of Cloud Computing has improved. I started by learning basic cloud concepts and system information. Later, I explored cloud platforms, containerization, object storage, application deployment, system monitoring, security, and Bash scripting. These activities helped me understand the importance of reliability, security, and efficiency in cloud operations.

Among the different roles, I enjoyed the Cloud-Native Engineer role the most because I learned how Docker containers can run applications in a more organized and portable way. I also found it interesting to access a deployed application through a browser. Overall, this semester gave me practical experience and made me more confident in using cloud technologies. I realized that cloud engineers need both technical skills and careful planning to manage systems successfully.
