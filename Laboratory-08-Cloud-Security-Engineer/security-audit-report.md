# Security Audit Report

## Mission Overview

In this activity, I learned about some basic security practices used to protect cloud servers. These practices help prevent unauthorized access and keep the server safe.

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that users should only have the access they need to do their tasks. This is important because it helps prevent users from accessing files or services that are not part of their responsibilities.

## 2. Attack Surface

An attack surface is the possible entry points that hackers can use to access a server or virtual machine. Examples include open ports, applications, and running services, so removing unnecessary services can help make the server more secure.

## 3. Default Deny Policy

A Default Deny Policy means that all incoming traffic is blocked unless it is allowed by a firewall rule. I think this is safer because we can control which connections are allowed instead of trying to block every hacker one by one.

## Conclusion

From this research, I learned that securing a cloud server is important to protect its data and services. Using the right permissions, closing unnecessary ports, and setting firewall rules can help reduce security risks.
