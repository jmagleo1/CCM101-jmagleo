# Reflection

Completing Mission 1 gave me an introduction to the basic responsibilities of a cloud infrastructure engineer. I learned how to access and work inside a cloud-based Linux environment using KillerCoda.

During the activity, I encountered different errors while creating files, managing directories, and connecting my local repository to GitHub. Some of the errors included "No such file or directory," Git commit errors caused by missing user configuration, authentication errors when pushing to GitHub, and a 403 Permission denied error. These errors were challenging at first, but they helped me understand the importance of checking file paths, configuring Git properly, and using the correct GitHub authentication method.

I learned how to navigate Linux using commands such as pwd, ls, cd, and mkdir. I also learned how to gather system information and manage files and directories.

Creating and organizing my GitHub Cloud Computing Portfolio also helped me understand the importance of documenting technical work properly. Troubleshooting the errors I encountered improved my patience and problem-solving skills.

Overall, this activity helped me develop basic Linux, documentation, Git, GitHub, and cloud computing skills. The errors I encountered were also valuable learning experiences because they taught me how to troubleshoot problems and carefully follow the correct procedures.
